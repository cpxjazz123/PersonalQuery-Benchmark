# iter 045: Phase 35.I-v2 — Strict attr filter + no word limit = 50.7% SOTA (K=4!)

**日期**: 2026-08-23
**承接**: iter_044 (Phase 35.I N=4 sweet spot 35.6%) + 用户反馈
  > 去掉 15-30 词硬约束,我们不管长度。长度应该是模型自然决定的。
  > 还是,属性应该是结构化的,属性不能选择那种有短语的,必须是字段+值的那种。
**目的**: 通过严格属性筛选 + 解除词数约束,看 rerank 质量能否突破

---

## V1 → V2 改动

### 1. 严格属性筛选 (`filter_useful_attrs_v2`)
| 维度 | V1 (旧) | V2 (新) |
|------|---------|---------|
| 短语值 (>5 词) | ✅ 接受 | ❌ 跳过 |
| 含 `. , ; :` | ✅ 接受 | ❌ 跳过 |
| 大小写重复 key | ❌ 都保留 | ✅ 跳过 |
| 单值字段保留数 | 15-46 个/asin | **6-14 个/asin** |
| 例: Care instructions (25 words) | ✅ 保留 | ❌ 跳过 |
| 例: "9.75 x 6.75 x 9.75 inches; 1.7 Pounds" | ✅ 保留 | ❌ 跳过 |
| 例: "Bottle Nipple Type" vs "Bottle nipple type" | ✅ 都保留 | ✅ 去重 |

### 2. 系统提示无词数限制
| V1 | V2 |
|----|-----|
| "Write ONE short natural sentence (15-30 words) with varied syntax." | "Length is up to you; include every attribute value." |

**效果**:
- avg_words: N=4 24.45 → 28.93 (+4.5)
- N=10 36.86 → 41.92 (+5)
- LLM 现在按属性数自然扩展长度

## 关键发现

### 1. **N=7 V2 = 50.7% SOTA** (K=4, not K=16!)
- Phase 35.G K=16 SOTA 也是 50.7%
- **V2 N=7 K=4 用 1/4 候选数追平 K=16 SOTA**
- 进一步 V2 N=7 K=16 应能 > 50.7% (候选多样性再涨)

### 2. **N=9 V2 mean_rank 5.11** ★★★
- V2 N=9 p90 = 8.75 (V1 N=4 p90 = 19.70, V2 N=7 p90 = 25.25)
- 几乎实现用户"错的时候别错得太远"目标 (mean < 10)
- 但样本量小 (n=36 users with pool≥10, 8 records with ≥9 attrs)

### 3. **V2 N=4..9 Rank-1 稳定在 43-50%** (无 V1 锯齿)
- V1: 35.6 / 21.9 / 26.0 / 34.2 / 23.3 / 34.2 / 30.1 (锯齿,信号受 N 影响大)
- V2: 45.2 / 43.8 / 43.8 / 50.7 / 43.1 / 44.4 / 36.4 (稳定平台)
- → 严格属性让 signal/noise 稳定,N 不再是主因

### 4. **Coverage → Ranking 单调关系确认**
- N=4: cov=65.1% → rank-1=45.2%
- N=7: cov=25.4% → rank-1=50.7% (更高!)
- N=10: cov=5.7% → rank-1=36.4%
- → **N=7 高 Rank-1 不是因为 cov 更高, 是 N=7 时 LLM 选择最优结构 (clause 数)**

### 5. **严格属性让 "compound value" 消失**
- "9.75 x 6.75 x 9.75 inches" → 不再保留 (含 `;`)
- "Soft NATURALATCH COMFORT silicone nipple" (5 词) → 不再保留
- → 留下来的都是原子 field:value,LLM 处理简单

## 最终 takeaway

> Phase 35.I-v2 严格属性 + 无词数约束, **N=7 K=4 = 50.7% SOTA** (追平 Phase 35.G K=16)。
> 三个关键动作:
> 1. 严格过滤 (>4 词短语 / 标点 / 重复 key 全跳过) → 留下 6-14 个原子 field:value
> 2. 去掉 "15-30 words" 硬约束 → LLM 自由决定长度,自然保证完整覆盖
> 3. K=4 候选即可达到 K=16 水平 → 验证"高质量候选 > 多候选"原则
>
> **Rank-1 稳定平台 43-50%** (V1 是 21-35% 锯齿), 严格属性把 signal/noise 锁稳。
> **full_cov 全部大幅跳升**: V1 N=4 14.4% → V2 N=4 65.1% (4.5x),N=6 0% → 41.1%。
> 下一步 V2 N=7 + K=16 多样性预期 > 55%,与 Phase 35.G softmax + V2 strict 联合是新 SOTA 路径。
