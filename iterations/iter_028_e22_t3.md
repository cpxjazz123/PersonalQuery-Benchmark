## §A 任务

**Issue #22 Task 3**：注入 Qwen 潜空间并验证 Query 句法控制
- projector 将 z_user (7 维) 映射为 soft prefix (16 tokens)，注入 Qwen2.5-1.5B
- 训练目标：内容生成损失 + style probe 风格对齐 + real-vs-shuffled 对比损失
- 四组控制：real-z / shuffled-z（z 距离最远用户）/ true-zero-z（显式零 prefix，绕过 projector）/ injection-off（无 prefix）
- 推理单次直接生成（批量 KV-cache 解码，无模板、无重排）

## §B 设计

### B1. 架构
- 模型：Qwen2.5-1.5B-Instruct（hidden=1536，冻结主干）
- `SoftPrefixProjector(7→128→16×1536)` + `alpha` gate（独立 LR×10 训练，从 0.008 增长到 0.5+，prefix norm 3.9→238 → prefix 才真正影响解码）
- `StyleProbe(1536→128→64→7)`：从 prefix 段 + target 段 pooled hidden 预测 z_user（双段监督）
- `CopyAwareHead`（E14 指针复制）：内容保真，属性值 verbatim 复制（用户确认启用）

### B2. 训练数据
- train+dev 用户 × 评论商品，top-5 属性（Brand/Color/Material/Category/Price）
- target query = **chosen 模板**（12 模板中 7 维句法特征距 z_user 最近的，Task 2 桥逻辑）——让 prefix 学"用户句法方向"
- 10 epochs，content loss 收敛 ~0.01-0.08
