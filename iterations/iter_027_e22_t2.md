## §B 设计与实施

### B1. 5 结构化属性（用户指定：Amazon 元数据 top-5 有实际语义属性）
全语料属性 key 频率扫描（meta_Baby_Products_2023，217,724 产品）：
- 排除无语义项：Batteries required（97.7% 为 "No"）、Is Discontinued By Manufacturer（布尔）、Item model number（ID 型）、Best Sellers Rank（排名）、Date First Available（日期）、Item Weight / Product Dimensions（用户判定无语义）
- **最终 top-5**：`Brand`(133k) / `Color`(98k) / `Material`(82.8k) / `Category`(叶子类目, 94% 覆盖) / `Price`(数值, 27.7% 覆盖)
- 每产品取这 5 个固定 key 的值 → 27515 产品齐全 → 2974 可用（用户评论产品交集）

### B2. 12 个句法多样模板（全部引用 A1..A5 全部 5 槽位）
- 模板在标点/嵌套/从句组织上明显不同：祈使短句、wh-从句、并列、状语前置、同位语、存在句、条件句、gerund、it-分裂、should 疑问、否定对照、破折号同位
- 每模板引用**全部** 5 个属性值 → chosen/rejected 内容 bit-identical，仅句法组织不同
- 模板仅用于构造训练监督（issue 允许）；Task 3 推理零模板

### B3. 内容一致性验证（逐对）
- 5 个属性值 token 序列必须同时出现在 chosen 与 rejected
- brand 值必须同时出现；数字 token 集合必须 bit-identical
- **0/1200 对跳过**（content_mismatch=0, same_dist=0）

### B4. chosen/rejected 构造与 encoder 输入（关键设计决策）
- chosen = 5 属性中性化 query 的 7 维特征距 z_user 最近者；rejected = 最远
- **内容中性化**（`neutralize_content`）：把 5 个属性值整体替换为固定占位符 `"xxxx"`，使同模板不同产品的 query 特征 bit-identical → encoder 只依赖句法骨架，杜绝品牌/价格/颜色词形泄漏
- 诊断过程（318 维 vs 7 维输入、MLP vs ridge、chosen-only vs chosen+rejected）见 §D
- **训练**：MLP(64,32) ReLU，chosen-only，train+dev 用户（test 用户完全未见）

### B5. 预注册误差门槛（用户级聚合，issue 语义）
- issue 明确 "以同一用户跨多个商品生成的 Query 集合做聚合句法验证"
- 预注册：每 test 用户对其 chosen queries 的 encoder 预测取均值 → 与 z_user 的 L2；相对 mean-baseline（train z_user 均值）ratio ≤ 0.90 且用户级改善 bootstrap CI 下界 > 0
- **实测**：agg encoder L2=1.955 vs baseline 2.374，**ratio=0.823**，改善 CI=[0.268, 0.574]

## §C 论文 vs PQB 现状对比反思

### 论文 [1] Gero et al. (2019) "Low-Level Linguistic Controls for Style Transfer and Content Preservation" (INLG 2019, arXiv:1911.03385)
**发现**：风格可建模为低层语言学控制（代词/介词频率、从句结构），保持内容词固定、调整控制即可转移风格；风格分类器可被骗 84%。
**PQB 现状**：Task 1 已定位 7 维 Query-compatible 句法特征（标点+嵌套）；Task 2 用**偏好对 + 可微 encoder** 建立"句法向量→Query 句法"桥梁，与 Gero 的"内容-句法解耦控制"思路一致。
**差距**：Gero 是**生成端**控制（decoder 直接受控制向量驱动）；PQB Task 2 只完成**判别桥梁**（encoder 预测 z_user），尚未在生成端实现句法注入（Task 3 的 Qwen projector 将承担该角色）。
**改进方案**：Task 2 的 encoder 必须**可微且输入为句法特征**（不能是模板匹配），并做内容不变性验证——本实现用内容中性化 + sanity/泄漏审计满足。
**落地验证**：encoder 输入 7 维中性化特征 → chosen/rejected 判别显著（CI=[0.855,1.425]）；sanity content_swap L2=0.000（内容任意替换输出不变）vs syntax_swap L2=2.847（句法改变输出可检测），完全对齐 Gero 的内容-风格解耦主张。

### 论文 [2] (2024) "Personalized Text Generation with Fine-Grained Linguistic Control" (arXiv:2402.04914)
**发现**：个性化文本生成需要细粒度语言控制，用户风格信号应在低层语言学特征上显式建模而非仅靠隐式 prompt。
**PQB 现状**：Task 1 用 7 维显式句法向量 z_user 作为用户风格信号；Task 2 encoder 从 Query 预测 z_user。
**差距**：论文主张显式细粒度控制；PQB Task 2 仅验证"判别桥梁"，生成端控制（soft-prefix / hidden-state 注入）待 Task 3。
**改进方案**：Task 2 预注册门槛采用**用户级聚合**而非单 query——正是"用户风格是跨查询一致信号"这一论文核心假设的检验。
**落地验证**：用户级聚合 ratio=0.823（单 query 级仅 0.93），证实聚合句法验证更贴近个性化生成的实际使用方式。

### 论文 [3] Ben-Ami et al. (2018) "Pull out all the stops: Textual analysis via punctuation sequences" (arXiv:1901.00519)
**发现**：标点序列本身携带强文体信号，可用于文本分析。
**PQB 现状**：Task 1 保留 7 维中 6 维为标点特征；Task 2 的中性化处理将属性值中的标点（如品牌 "J.L."）彻底抹除，只保留**模板标点**。
**差距**：论文在整文本上分析标点；PQB 在**短 Query** 上使用标点特征，面临内容词标点污染（品牌点号/撇号）问题。
**改进方案**：内容中性化 + sanity content_swap=0 验证，确保短 Query 标点特征纯净（无内容词标点泄漏）。
**落地验证**：token-swap 审计 L2=0.118 ≤ 0.15（替换品牌/价格词形后 encoder 输出几乎不动）；早期版本 token-swap L2=1.87（内容词标点泄漏）→ 修复后降至 0.118，正负对比明确。

### 论文 [4] (2025) "Stylometry recognizes human and LLM-generated texts in short samples" (arXiv:2507.00838)
**发现**：短样本（单句/短 Query 级别）上文体识别仍可行。
**PQB 现状**：Task 2 在单句 Query 上计算 7 维句法特征并预测 z_user。
**差距**：论文显示短样本判别可行但噪声大；PQB 实验证实单 query 级误差 ratio≈0.93，聚合后 0.82。
**改进方案**：预注册门槛必须定义在用户级聚合（issue 也如此要求），避免单 query 噪声造成假阴性。
**落地验证**：delta mean=1.3913（单 query 级 bootstrap CI 下界 0.855）与聚合 ratio=0.823 双重显著，与论文"短样本可判别"结论一致。
